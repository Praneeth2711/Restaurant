# Suhas | Premium Restaurant Experience

A modern, high-end portfolio project website for a luxury fine dining restaurant. Built with **Next.js**, **Tailwind CSS**, and **Framer Motion**, this project features a premium design language inspired by industry leaders like Stripe and Apple.

## ✨ Features

- **Immersive Design:** Cinematic hero section, large typography, and glassmorphism UI elements.
- **Buttery Smooth Scrolling:** Integrated Lenis smooth scroll for a premium feel.
- **Advanced Animations:** Scroll-triggered animations, parallax effects, and smooth page reveals using Framer Motion.
- **Interactive UI:** Hover-expand signature dish cards and animated statistical counters.
- **Fully Responsive:** Tailored for seamless viewing on desktop, tablet, and mobile devices.

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS (v4)
- **Animations:** Framer Motion
- **Scrolling:** Lenis
- **Icons:** Lucide React (with custom inline SVGs)
- **Typography:** Cormorant Garamond, Inter, Space Grotesk

## 🚀 Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 🎯 Project Overview

This project was developed to demonstrate the ability to build and pitch a realistic, high-quality local business website using modern, industry-standard frontend tools.
